# Mo × OKI – live demo (Anna)

Scripted demo of a bank's own assistant for the Bank Pekao meeting:
Pulse spots the moment, Monthio understands the customer, the assistant acts (opens and funds an OKI).

Illustrative data only. No backend, no API keys.

```bash
npm install
npm run dev     # local
npm run build   # static site in dist/
```

Navigate with the arrow keys: → / Space / Enter forward, ← back.
